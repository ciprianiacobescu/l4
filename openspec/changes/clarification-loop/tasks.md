## 1. Walking skeleton (M1)

Slice: the clarifier answers `questions.md` through an LLM backend (`openai-chat`) or an agent profile (`claude-code`, `opencode`);
the S1 checks are served by `LlmBooleanJudge` on the `s1_judge` chain only when `clarifier.s1_standin: llm_boolean` is set (default `none`); unanswered questions put the unit in `awaiting_human`
(exit 11) with the label and sticky comment; a human answer committed to the unit branch is consumed on the next run and injected
into the implementer prompt. Depends on agent-factory (`Factory.for_role`, `LLMBackend`, `AgentAdapter`, `FakeBackend`) and
spec-providers (`l4.specs.questions`). Run all commands from the repository root.
