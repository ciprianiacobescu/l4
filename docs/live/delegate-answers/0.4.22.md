## Findings

- **F1 (doctor, minor): DLG-001 passes a chain whose every verdict question escalates.** With
  `roles.delegate: [delegate-ds, delegate-free]`, DLG-001 says `roles.delegate: delegate-ds, delegate-free; every
  implementer and judge has an independent one`, and run 39642770691 escalated both verdict questions `no
  independent delegate`. `_joint_problems` (`src/l4/doctor/checks_delegate.py:175`) checks independence of the joint
  askers without the kinds veto, and `_kinds_problems` (`:88`) checks the kinds without independence; the profile
  that is independent of the judge and the implementer at once (`delegate-free`) may not answer verdicts, and the
  one that may (`delegate-ds`) is not independent. The escalation is fail-safe (a person answers), but the doctor
  should name it at configuration time, as A5 intends for "a kind no profile of the chain may answer".
- **F2 (delegate pass, design): a transient hello failure escalates a question for good.** The probe classes a hello
  timeout as `failure_class: transient` (`src/l4/availability/probes.py:158`), the factory records `retry_after: null`,
  and `_unavailable` (`src/l4/delegate/run.py:668`) defers only for a profile that is cooling with a known end, so the
  question escalates; an escalation is final for its raise, so the delegate never asks it again. This follows
  L4-DLG-013's text, which lists `hello` among the causes only a fix ends, but for a free Zen endpoint a 60 s hello
  timeout is usually the endpoint, not the configuration, and one slow hello hands the question to a person. A
  deferral (with the attempts limit as the bound) for a `transient` hello would match the probe's own class.
- **F3 (hint, observation):** the `Hint:` line is shown for a unit whose open question the delegate already escalated
  (`add-late-fee`); turning the delegate on would not ask it again. B1 as specified counts any open question of a kind
  in `delegate.kinds`.
- **F4 (upgrade output, cosmetic):** `l4 upgrade` printed `re-rendered .github/workflows/l4.yml (0 lines changed)`
  for a re-render that removed the `KIRO_API_KEY` line: the count is of added lines only
  (`src/l4/init/upgrade.py:276`).
- **Known, unchanged (P2 backlog of the first live test):** the judge does not see `questions.md`, so on
  `add-commission` it wrote a minor finding that "the code picks banker's rounding" against a proposal that said to
  ask, although the delegate had answered Q-001 from the money rules.
